# 课堂点名簿

一个移动优先的静态网页应用：记录 Zoom 线上课的出勤与上麦次数。所有业务数据、截图 OCR 和导出均由浏览器在本机完成；不需要数据库或后端服务。

## 本地预览

```bash
cd /Users/dongyu/Developer/online-class-attendance
python3 -m http.server 4177
```

用浏览器访问 `http://127.0.0.1:4177`。默认密码为 `1234`，首次进入后可在“设置”中修改。

## 部署

这是纯静态应用。把整个目录上传至任意静态网站服务（腾讯云 COS 静态网站、腾讯云轻量服务器的 Nginx、Cloudflare Pages 等）即可；入口文件是 `index.html`。

部署后应使用 HTTPS 打开，因为手机浏览器对本地图片处理和下载在 HTTPS 页面上的兼容性更好。注意：每台设备的 localStorage 独立，数据不会自动同步；换机或清浏览器数据前，请在“设置”导出 JSON 备份，再在新设备导入。

## 校验

```bash
npm test
npm run test:coverage
```

核心统计与别名匹配逻辑的覆盖率为 97.5%。移动端浏览器烟雾测试覆盖登录、统计、历史编辑入口。

## 内置数据口径

需求文档中“逐次明细”与“累计结果”有三处冲突：7/12 的梅子/张启梅上麦、8/9 的罗莉出勤。初始数据以第 7.3 节的验收累计结果为准，以确保应用初始统计可逐人核对。
